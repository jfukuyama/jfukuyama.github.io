Final project guidelines

You need to submit reproducible code and a writeup and give an oral defense of your analysis. The ideal submission format is as a GitHub repository (it can be private if you want; just invite me, jfukuyama, so that I can see it). A zip file with code and writeup submitted through Canvas is also acceptable. If you are doing one of the projects I set up, make sure that your writeup addresses the questions raised in the project description. If you have a custom project, your writeup should address what you did.

For the oral defense, you can sign up for a time slot here, or you can email me. There are slots on Monday/Tuesday/Wednesday during exam week, as well as some earlier ones if you want to be done earlier. You will need to submit your code/writeup by the day before you are scheduled to meet with me. The last day you can do the oral defense is December 16, which would also require submitting your writeup by December 15. During the oral defense, I will ask you questions about your analysis.

You are allowed to use language models, etc., for anything, including the writeup, but to do well, you will need to demonstrate to me that you understand the analysis. I will mainly ask about your understanding of the model you are fitting, the way you fit the model, how you would check the fit.

In particular, I will want to know whether you can:

  • Explain your generative model. For instance, what assumptions about the data does it make, what roles do the parameters play?
  • Explain how you fit the model. For instance, what features did you use, how did you find them, how do you know whether they’re any good?
  • Evaluate your fitted model. How did you/would you check various aspects of the model? Is there anything the model can’t reproduce? Are the parameters identifiable? How much uncertainty is associated with the parameter estimates? How do you know?
